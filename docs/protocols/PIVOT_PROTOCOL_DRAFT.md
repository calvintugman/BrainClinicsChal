## 3. Evaluation (applies to A, B, C)
Same saved outer splits (5-fold, seeds 42/43/44), inner 3-fold, patient-level rows, windows never counted as patients. Threshold from inner OOF only (max PPV s.t. sens>=0.5). Report per repeat: AUC, nPPV, achieved sensitivity, PPV, balanced accuracy, Brier, calibration (reliability curve), predicted-positive counts, TP/FP/TN/FN; ROC and precision-recall plots. No single ranking axis mixing metrics.
Learned cohort transforms (PCA, scalers, imputers) refit inside every training split. A reference model for the extension may be fixed only if its pool is disjoint from the 164 and uses no outcomes.
Multiplicity: confirmatory family = {A-Responder, B-Remitter, extension-Remitter} (3 pre-declared primary tests); Holm correction on bootstrap/permutation p-values; permutation must refit everything (PCA, selection, tuning, thresholds) with folds regenerated from permuted labels (>=199 perms), and for the family compute the max over the 3 methods. All results labelled exploratory because the cohort was already used for 2 null batches; seeds do not restore untouched status.
Continuation rule (set now): continue a pipeline only if mean Remitter (A: Responder) AUC >= 0.60, gain >= 0.05 over E01c, positive gain in each repeat, AND the result is stable (|AUC change| <= 0.03) between v1 and v2 cleaning. Otherwise stop it.
Stop rules: label-free feasibility failure, cleaning dominance (feature-agreement r < 0.9 for the pipeline's main features), or no credible gain over matched controls.

## 4. Conditional EC->EO extension (outline only; NO outcome labels touched)
Reference pool: non-rTMS discovery people with EC and EO (1,129 by manifest; mixed-diagnosis POPULATION reference, not healthy norms; healthy-only = 179 workbook-HEALTHY). Disjoint from the 164 by ID (checked). Pool recordings processed with v2 cleaning (~50 min est.).
Inputs: the 12 log absolute powers (3 ROIs x delta/theta/alpha/beta) per condition (split-half r about 0.96-0.99 in the baseline reliability figure); NOT E13 eigenvalues.
Mapping f: ridge regression EC(12) -> EO(12), fit on reference-train; validated on held-out reference people vs a mean predictor (must beat it in held-out R^2/MSE before any treatment analysis); more complex mapping only if it improves held-out reference prediction first. Residual standardization with reference-training (cross-fitted) residual SD.
Treatment models (matched regularization, same folds): (1) EC+EO concatenated (24), (2) EO-EC signed contrast (12), (3) deviation EO - f(EC) (12). Controls: shuffled-pair f (EC/EO pairings shuffled within reference-train), cleaning-view robustness (v1 vs v2 pipelines for both reference and patients; condition-wise agreement, not EC/EO forced agreement).
Limitations stated in advance: a linear residual is a reparameterization of EC and EO, so apparent gain may be regularization; better reference reconstruction does not imply remission prediction; separate recordings are not a time-locked switch (not an oddball substitute); age/sex adjustment would be a separate frozen decision; no clinical predictors.
Novelty: provisional; normative-connectivity (Tong 2024) and EC-EO work exist (memo); no claim.
