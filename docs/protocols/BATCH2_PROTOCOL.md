## Challengers (7; no additions after scoring)
- E10: unchanged 65 E01 features -> HistGradientBoostingClassifier(learning_rate=0.05, max_iter=150, early_stopping=False, min_samples_leaf=20, random_state=repeat seed); grid max_leaf_nodes {3,7} x l2_regularization {1,10}; train-fold median imputation, no scaling. (Parameters verified in installed scikit-learn 1.9.1.)
- E11 (specparam 2.0.0rc7, SpectralModel(aperiodic_mode='fixed', peak_width_limits=(1,8), max_n_peaks=4, peak_threshold=2.0, min_peak_height default 0.0), fit range 2-40 Hz, linear PSD uV^2/Hz). PSD per recording = mean over clean 4-s Hann windows (same windows as baseline) and over non-interpolated channels of each ROI (frontal/central/posterior as baseline). Fit accepted iff finite parameters and r^2 >= 0.90 (gof_rsquared), else all 4 values missing. Features per ROI x {EC,EO}: aperiodic exponent, offset (log10 uV^2/Hz), alpha CF (largest-height peak with CF in [8,12]; missing if none), alpha height (peak PW, log10 units above aperiodic; 0 if accepted fit has no alpha peak). 24 features. E11-only = 24; E11-add = E01 + 24.
- E12-add: 26-channel (fixed SCALP order) covariance, bands theta 4-8, alpha 8-12, beta 12-30, EC and EO. Cleaned (post-ICA, interpolated channels retained in the 26-ch space; interpolation burden logged separately, aux channels never used) continuous data are band-passed (MNE FIR firwin, zero-phase, auto transition) over the whole trimmed recording; epochs = non-overlapping 4 s; epoch valid iff all-scalp peak-to-peak <= 150 uV in the 4 s (0.5-45 Hz cleaned data, same as baseline) AND no 1-s block with ptp > 150 uV within 1 s before/after (margin vs filter smear). First 20 valid epochs per condition; <20 -> that condition's matrices missing (primary definition; EC/EO both use 20). Per-epoch Ledoit-Wolf (sklearn, samples x channels, units uV^2), averaged over epochs. Checks: symmetric, finite, positive definite. Trace-normalize; fit pyriemann TangentSpace(metric='riemann', tsupdate=False) per condition/band on valid training matrices only; missing -> replaced by that reference (zero tangent vector); concatenate 6 x 351; train-fit StandardScaler; PCA(n_components=20, svd_solver='full'); append 20 scores to E01 (imputed, standardized) -> common logistic pipeline.
- E13: same unnormalized shrunk covariances; per band eigh(C_EO, C_EC) (scipy.linalg.eigh generalized symmetric-definite solver), natural log of eigenvalues, features mean, population SD (ddof=0), min, max -> 12. Missing if either condition missing. E13-power = 12 features ln(P_EO)-ln(P_EC) for 3 ROIs x 4 bands (from existing EC/EO log-abs power). E13-relative = 12 eigen features alone. E13-add = E01 + 12 eigen features. Pre-scoring synthetic checks (identical matrices -> log lambda ~ 0; common scalar gain -> unchanged) in scripts/09_synthetic_checks.py. Known limitation recorded in advance: ICA removal of up to 3 components and interpolation make the 26-ch covariance rank-deficient; Ledoit-Wolf makes it positive definite but the smallest generalized eigenvalues (and so min/max/SD) may be dominated by shrinkage-floor directions. Effective-rank/condition diagnostics are reported; the design is not changed.
- Label-free gain sensitivity: frozen outer-fold models (seed 42) applied to test patients with common gains 0.5 and 2 applied to both conditions (power-type features: log abs power +2 ln g; E11 offset +2 log10 g; E12/E13/rel/FAA/entropy/connectivity/IAF/contrast invariant by construction, verified numerically for E13 from rescaled covariances). Report prediction change; no retuning.

## Evaluation, screening, statistics
All 7 on both endpoints and all 3 repeats. Primary screen: mean outer pooled-OOF AUC over 3 repeats for Remitter, every repeat shown. Secondary: nPPV, sensitivity, PPV, Brier, balanced accuracy, TP/FP/TN/FN. Paired patient bootstrap (2000 draws, same draws as baseline bootstrap rng seed 1, same draws across methods; mean-over-repeats statistic resamples patients jointly across repeats; threshold decisions retained); conditional on saved predictions, not corrected for choosing among 7.
Triage rule (fixed now): mean Remitter AUC >= 0.60 AND mean AUC gain over E01 >= 0.05 AND positive AUC gain in each repeat. If any qualifies: batch-aware permutation, >=199 label permutations, all 7 challengers refit per permutation (folds regenerated from permuted labels with the same seed rule), null of the best mean AUC; plus-one p; else report as not qualifying. If compute is insufficient, checkpoint and say incomplete.
No stacking/ensemble. Budget 12 h wall-clock; workers chosen from cores/memory (16 cores, ~8 GB free -> 10 workers).
Reliability: split-half (halves separated by one window / interleaved non-overlapping epochs), valid N per feature, no imputed values.
