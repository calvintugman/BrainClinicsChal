# AGE/SEX PROTOCOL = AMENDMENT A8 (FROZEN 2026-10-08 before any model below was fit; written while A7 was still running)
EXPLORATORY pivot. Reason: A6/A7 suggest the MDD-vs-healthy result is cohort/batch-driven, and the prognostic arms are null. Age and sex prediction from EEG (a) have ~950 labelled adults (not 164), (b) are listed on the user's leaderboard screenshot as separate categories (age R2 52%, sex balanced accuracy 85% by one entrant; whether they are prize categories is not stated on the rules page I read), (c) label the person, not a recording cohort. Cohort confounding still exists (age distributions differ by cohort), so within-cohort results are reported. Not a submission; no replication data used.
Cohort: all adults (age >= 18) with v2 features and workbook age/sex (patients' session-1 row; pool one session each; exact-duplicate vectors dropped) = about 950 people, one row each.
Feature sets: F65 = the 65 E01c columns; F81 = all 81 v2 columns (adds the extra connectivity/IAF-type columns present in the pool and patient files). Train-fit median imputation + StandardScaler.
Models (fixed, no further search): AGE: Ridge (alpha {0.01..1000}, inner 5-fold) and HistGradientBoostingRegressor (lr 0.05, 150 iters, no early stopping, min_samples_leaf 20, max_leaf_nodes {3,7} x l2 {1,10} by inner 3-fold MSE). SEX: L2 logistic (C {0.01,0.1,1,10}, inner 5-fold log loss) and HistGradientBoostingClassifier (same grid, inner log loss). 2 feature sets x 2 models x 2 targets = 8 models, ALL reported.
Evaluation: 5-fold outer CV x seeds 42/43/44 (KFold shuffled for age; StratifiedKFold for sex). Age: R2, MAE, Pearson on pooled out-of-fold predictions per repeat. Sex: AUC and balanced accuracy at the 0.5 threshold (no tuning). Cohort breakdown (descriptive): the same metrics computed within MDD patients (n~164), within healthy (n~163) and within the remaining pool people, to show whether performance is only between-cohort age/sex structure. Bootstrap 95% intervals (2000 draws, rng 1, joint across repeats). One permutation check per target for the best-by-AUC/R2 model is NOT run (the target is a measured covariate, not a clinical outcome); instead the within-cohort breakdown is the control.
Frozen interpretation: report all 8 models; "usable" = age R2 >= 0.30 within EVERY cohort subgroup, or sex BA >= 0.70 within every subgroup; otherwise "partly cohort-driven". No post-result changes; no new features.
