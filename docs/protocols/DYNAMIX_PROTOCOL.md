# DYNAMIX PROTOCOL (FROZEN 2026-10-05T09:15:57+0800; before ANY DynaMix outcome scoring; seed budget K chosen from outcome-blind non-rTMS data)
EXPLORATORY. Same 164 patients already used in baseline, Batch 2 and E01c. Session-1 = pretreatment is an unverified assumption. This is NOT a confirmatory test, NOT a test of superiority over E01c, and not a replication of Tolley et al. (whose EEG choices are unknown). Defers Bailey/pyhctsa, fine-tuning, submissions, author contact. clean_v2 is fixed.
Three questions are kept distinct: (1) is the DynaMix representation numerically stable/useful as an EEG representation (label-free); (2) does it predict remission (patient-level OOF); (3) does pretraining help (pretrained vs three random-weight models of the same architecture).

## Input signals
v2-cleaned (clean_v2, unchanged) 26 scalp channels in the order of scripts/common.SCALP (Fp1,Fp2,F7,F3,Fz,F4,F8,FC3,FCz,FC4,T7,C3,Cz,C4,T8,CP3,CPz,CP4,P7,P3,Pz,P4,P8,O1,Oz,O2), linked-mastoid reference as acquired, units microvolts, 50 Hz notch + 0.5-45 Hz FIR band-pass + ICA already applied; auxiliary channels never used. Whole record resampled to 100 Hz (mne FIR resample).
Eligibility: 1-s blocks of the 500 Hz cleaned data with any-channel peak-to-peak > 150 uV are bad; bad blocks dilated by 1 s on each side; maximal contiguous clean runs; non-overlapping 30-s (3000 samples) windows tiled from the start of each run; remainder < 30 s discarded; fragments from different runs are NEVER concatenated. Selection: first up to 4 windows chronologically per recording. Recording with 0 windows (or ICA failure) = missing for that condition. (scripts/21_dynamix_prepare.py; 320/328 patient recordings processed, 8 ICA failures; windows per recording 0:25, 1:16, 2:37, 3:155, 4:95.)

## Extraction (scripts/dm.py; exact indices)
Each channel is an independent univariate series (batch of 26). Per-series z-scoring over the window (package preprocessor, amplitude therefore discarded) and positional embedding (deterministic sinusoids at the autocorrelation period) to N=6. z_0: first 6 dims = embedded final context sample; remaining dims = B x that sample (as DynaMixForecaster._init_latent_state). Horizon H=200 steps (2 s). For t=0..199: gate w_t = gating_network(context, z_t) with ONE noise draw; z_{t+1} = sum_e w_t[e] * expert_e(z_t) (identical to DynaMix.step but reusing w_t; note my earlier feasibility demo drew separate noise for logging, superseded).
Per series 12 values: mean over t=1..200 of z_t[0..9] (post-update states); mean over t=0..199 of gate entropy (-sum w log w); mean over t=0..199 of max_e w_t[e]. Per recording-condition: 26 channels x 12 = 312 values (channel-major).

## Randomness (all resolved)
Embedding is deterministic. The only stochastic element is gating noise (torch.randn inside the gating network). K independent noise replicates run as a batch (B=26K) from one torch seed per (model, recording index r, window w): seed = 7,000,000 + 1000 r + 10 w + m, m = 0 pretrained, 1/2/3 random_a/b/c; recording index = row of window_manifest_patients_PRIVATE.csv. Random-weight init seeds above.
Seed budget (outcome-blind, scripts/22_dynamix_seed_budget.py): fixed-seed (7) draw of 24 non-rTMS pool recordings; 13 had an eligible window (11 did not: heavy artifact), first window of each, 4 models x 16 replicates. Criterion fixed beforehand: smallest K in {1,2,4,8} with, in ALL four models, median over the 12 feature types of the A-vs-B (disjoint K-replicate means) correlation >= 0.95 and min >= 0.90; otherwise K = 8. RESULT: pretrained passes at K=2 (min r 0.90) and K=8 (min 0.974); random_a fails at every K (gate entropy r=0.82, gate max 0.90 at K=8), random_b/c pass or nearly; latent-mean features r ~ 1.0 everywhere. Criterion not met by all models -> K = 8 (frozen). Runtime accounting: K=8 batch ~10-14 s per 30-s window per model; 935 patient windows x 4 models.

## Patient features and model
Per patient: EC 312 + EO 312 concatenated = 624 features (window mean of replicate-mean embeddings; windows never counted as patients). Missing condition (0 windows/ICA failure) -> its 312 values NaN; training-fold median imputation -> StandardScaler -> L2 LogisticRegression, C in {0.01, 0.1, 1, 10} by inner (3-fold) log loss; no PCA. Four models: pretrained, random_a, random_b, random_c, each fitted/reported separately. Comparator: saved E01c on identical 164 patients and identical splits (5 outer folds, 3 inner, seeds 42/43/44; StratifiedKFold(shuffle) rule; threshold = max inner-OOF PPV s.t. sensitivity >= 0.5, ties higher sensitivity, applied unchanged).

## Evaluation and inference
Primary endpoint Remitter; Responder secondary (same design, no permutation). Report per repeat: AUC, nPPV, achieved sensitivity, PPV, balanced accuracy, Brier, positive calls, TP/FP/TN/FN; ROC/PR (seed 42 primary, all repeats shown), calibration (reliability), patient-level paired differences (mean per-patient log-loss difference averaged over repeats, pretrained minus E01c and minus each random model), paired patient bootstrap (2000 draws, rng seed 1, joint across repeats, same draws for all methods; conditional on saved predictions, not accounting for training/tuning uncertainty).
ONE inferential procedure: label-permutation test of the pretrained model's mean (over 3 repeats) Remitter AUC against chance: 999 permutations (rng seed 11), each permuted label vector re-runs the full frozen pipeline for each repeat (folds regenerated from the permuted labels with the same random_state rule, inner tuning, C selection, thresholds); plus-one p = (1+#{null >= observed})/1000. Frozen embeddings (label-independent) are cached and reused. This tests association with remission beyond chance for the pretrained pipeline only; it is NOT a test of superiority over E01c or of pretraining benefit; no multiplicity correction is claimed (single prespecified test), random controls and Responder are descriptive.
Triage (funding decisions, unchanged numbers): mean Remitter AUC >= 0.60, mean AUC gain over E01c >= 0.05, positive AUC gain in every repeat. v1-v2 cleaning sensitivity (E01 0.517 -> E01c 0.577; feature agreement r, incl. FAA 0.70-0.82) and the conditional availability analysis are REPORTED as sensitivity diagnostics, not vetoes; no thresholds change after results.

## Reference pool (outcome-blind)
Non-treatment, non-rTMS discovery people (848 'other discovery' + 175 workbook-HEALTHY = 1,023 with EC+EO; the earlier "1,129" included 106 ADHD-NF/OCD treatment-cohort people, now excluded as instructed), one session per person (lowest with both conditions; handles the two healthy people with duplicate ses-1/ses-2 files), exact-duplicate feature vectors dropped, replication folders never read. v2 features (log abs power, 3 ROIs x 4 bands, EC and EO). Ridge EC->EO on standardized values; fixed 80/20 person split (rng 2026); alpha in {0.01,...,1000} tuned only by 5-fold CV inside training people; evaluation vs training-mean predictor on held-out people: per-feature MSE/R^2, aggregate, and 20 shuffled-pair controls; no remission scoring, no alternative mappings (scripts/26_reference_mapping.py).
